# Investa – Investment Platform Landing Page

Investa is a modern, finance-focused landing page for an investment platform that helps users discover, evaluate, and grow their wealth through curated global investment opportunities. It features a sleek dark-accented UI, live-style data widgets, and conversion-focused sections.

## ✨ Features

- **Hero Section** – "Investing Simplified" headline with description, rating badge (4.9★), "Get Started" CTA, and video play button
- **Income Widget** – Floating income/earnings card with a weekly bar chart (Sun–Sat)
- **Navigation Bar** – Home, Pages (dropdown), Opportunities, Service, About, and "Sign In" button
- **Investment Opportunities Grid** – Cards showing project name, valuation, investor count, funding amount, location, and "Learn More" link
- **Fortify Your Financial Horizon** – Value proposition section with three highlights: Live Market Insights, Ventures Across Diverse Industries, Revolutionary Investment Solutions
- **Smart Investment Solutions** – Section intro for the solutions/services showcase
- **Stats Section** – Team/consultation image paired with key metrics: 5k Investors, 96+ Assets, 879 Objects
- **Features Showcase** – "Invest with Precision Today" — three image-overlay cards (Spotlight on Global Investments, Master Dynamic Markets, Elite Opportunities for Astute Investors)
- **Partner/Client Logos** – Row of partner brand logos (placeholder "Logoipsum")
- **Founder Spotlight** – "Meet Our Visionary Founder" quote card with founder name and title
- **FAQ Accordion** – Expandable Q&A section covering services, global reach, property investments, and consultation process
- **Footer** – Social links (Facebook, Twitter, YouTube), office address, contact email/phone, and quick links (Menu: Service, Feature, Partner, Testimonial; Links: About, Contact, Help Line, Marketing, Testimonials)

## 🛠️ Tech Stack

- HTML5 / CSS3
- JavaScript (or React / Next.js)
- Tailwind CSS (utility-first styling, rounded cards, soft shadows)
- Chart library (e.g. Chart.js / Recharts) for the income bar chart

## 🚀 Getting Started

### Prerequisites
- Node.js >= 18
- npm or yarn

### Installation

```bash
git clone https://github.com/your-username/investa.git
cd investa
npm install
npm run dev
```
